# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

Please do NOT open a public GitHub issue for security vulnerabilities.

Instead, open a private security advisory at:
https://github.com/imchitraarth/github-profile-lab/security/advisories/new

We will respond within 7 days. If the issue is confirmed, we will release a patch as soon as possible.
