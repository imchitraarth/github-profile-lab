# 🧪 github-profile-lab

> An open-source lab for documentation, GitHub templates, utilities, and GitHub Actions experiments.

[![Markdown Lint](https://github.com/imchitraarth/github-profile-lab/actions/workflows/markdown-lint.yml/badge.svg)](https://github.com/imchitraarth/github-profile-lab/actions/workflows/markdown-lint.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![Contributions Welcome](https://img.shields.io/badge/contributions-welcome-brightgreen.svg)](./CONTRIBUTING.md)

## 📦 What's Inside

| Path | Description |
|------|-------------|
| `tools/badge_generator.py` | Generate GitHub README badges from CLI |
| `.github/workflows/` | GitHub Actions CI for linting |
| `.github/ISSUE_TEMPLATE/` | Bug report & feature request templates |
| `docs/` | Documentation and guides |

## 🚀 Getting Started

```bash
git clone https://github.com/imchitraarth/github-profile-lab.git
cd github-profile-lab
python tools/badge_generator.py --help
```
