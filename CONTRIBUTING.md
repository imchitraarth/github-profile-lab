# Contributing to github-profile-lab

Thank you for your interest in contributing! 🎉

## How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/imchitraarth/github-profile-lab.git
cd github-profile-lab
git checkout -b feat/your-feature-name
```

### 2. Make Changes
- Keep commits small and focused
- Write clear commit messages (`feat:`, `fix:`, `docs:`, `chore:`)
- Update documentation if needed

### 3. Open a Pull Request
- Push your branch to your fork
- Open a PR against `main`
- Describe what you changed and why

## Code Style
- Python: follow PEP 8
- Markdown: use markdownlint-compatible style
- Keep files < 500 lines where possible

## Issue Templates
Use the provided issue templates for bug reports and feature requests.

## Co-authoring
If you pair with someone, add to your commit message:
```
Co-authored-by: Name <email@example.com>
```

## Questions?
Open a Discussion or an Issue — we are friendly! 😊
